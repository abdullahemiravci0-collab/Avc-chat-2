# 🏹 Avcı Chat

**Avcı Chat**, gerçek zamanlı mesajlaşma, sesli arama ve görüntülü arama özelliklerini tek bir platformda sunan modern bir web sohbet uygulamasıdır. 

Node.js, Socket.io, MongoDB ve WebRTC altyapısı kullanılarak geliştirilmiştir.

## 🚀 Özellikler

- 💬 **Gerçek Zamanlı Mesajlaşma:** Socket.io ile anlık mesajlaşma.
- 📞 **Sesli Arama:** WebRTC destekli, düşük gecikmeli sesli görüşme.
- 📹 **Görüntülü Arama:** Kesintisiz görüntülü konuşma imkanı.
- 💾 **Kalıcı Veri:** MongoDB entegrasyonu sayesinde mesajlar ve kullanıcılar kaybolmaz.
- 👥 **Online Kullanıcı Takibi:** Anlık olarak çevrimiçi avcıları görme.
- 🎨 **Modern Arayüz:** Kullanıcı dostu, karanlık tema (Dark Mode) tasarımı.

## 🛠️ Teknolojiler

- **Frontend:** HTML5, CSS3, Vanilla JavaScript
- **Backend:** Node.js, Express.js
- **Sinyalleşme & Mesajlaşma:** Socket.io
- **Veritabanı:** MongoDB & Mongoose
- **Gerçek Zamanlı İletişim:** WebRTC
